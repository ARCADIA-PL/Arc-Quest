# Arc Quest 1.21.1 移植说明

本次同步 `master`（Minecraft 1.20.1 Forge）从 `382e913e` 之后到 `43d3606b` 的 11 个提交。远端 1.21.1 基线 `ed553868` 已包含图鉴调查、JEI 和之前的框架修复。本次保留 NeoForge 的玩家附件和注册表，网络协议从 23 升到 24，联机时请同时更新客户端和服务端。

## 玩家可用功能

| 功能 | 怎么用 |
| --- | --- |
| HUD 美术风格 | 在「模组列表 → Arc Quest → 配置 → 通用」里切换。五种风格：默认、Ore、Moderna、Cyberpunk、Wyrmheart。即时生效，独立于任务追踪器排版。详见 [HUD 美术风格](../HUD_ART_STYLES.md)。 |
| 商店搜索 | 完整商店和快捷商店都能按当前语言的商品名、商品 ID 和奖励名称搜索。支持有序模糊匹配，例如「神刀」能找到「神龙刀」。多个关键词用空格分隔；分类和服务端可见性依然有效。 |
| 左侧指南阅读器 | 正文可用滚轮、滚动条、`Home` / `End` 或 `Page Up` / `Page Down` 浏览，使用方向键或 `A` / `D` 翻页。`Aa` 调整字号，返回后保留页码与阅读位置。详见 [指南布局与操作](Guide侧栏布局与验证.md)。 |
| 对话交付 | 支持从目录选择一种样本、提交固定配方，或一次选择多种样本。固定配方会显示缺项，自动填充按背包库存选择材料。能否提交、实际扣除与后续对话由服务器决定。 |
| 显示和交互修复 | 任务标记的描边不再压住字形；指南换行保留富文本样式；图鉴示例改用灰色主题；服务器主动结束对话会通知客户端；NPC 扩展对话支持非 ASCII 玩家名。 |

## 整合包与附属模组接入

### 对话交付

先在服务端代码中用 `DialogueSubmissionRegistry.register(definition)` 注册目录，再给对话选项添加 `new DialogueAction.OpenSubmission("example:research_samples")`。JSON 对话选项也可引用已注册目录：

```json
{
  "type": "open_submission",
  "submissionId": "example:research_samples"
}
```

把该对象放在选项的 `actions` 中，由交付定义中的 `successNodeId` 决定成功后的节点，打开面板的选项留在当前节点。目录本身是 Java 注册内容。

| 模式 | 定义方式 | 交付规则 |
| --- | --- | --- |
| 单样本 | `new DialogueSubmissionDefinition(id, title, entries)` | 每个 `Entry` 提供物品 ID、可见条件、交付动作和成功节点；每次确认一件样本。 |
| 固定配方 | `DialogueSubmissionDefinition.bundle(id, title, bundle)` | `Bundle` 提供完整的物品数量清单、门槛条件、交付动作和成功节点；所有材料齐全才允许确认。 |
| 多样本 | `DialogueSubmissionDefinition.batch(id, title, entries, batch)` | 每个选中条目代表一件样本。服务器先校验所有选择并汇总同物品的数量，再按目录顺序调用一次 `BatchCommit`。 |

登记需求只负责展示和校验。扣除材料、发奖励及失败回滚应在附属模组的交付动作或 `BatchCommit` 中一次完成。客户端传入的是条目 ID，不应由客户端决定奖励或支付内容。

### 指南生命周期

需要获知教程何时实际打开、暂停或结束时，服务端可调用 `GuidePresentationService.open(player, guideId)` 取得专用令牌，然后监听 NeoForge 游戏事件总线上的 `GuidePresentationEvent`。用 `getToken()` 关联这一次展示，用 `getStage()` 区分 `OPENED`、`SUSPENDED`、`RESUMED`、`CLOSED` 和 `CANCELLED`。`cancel(player)` 取消本次专用展示；解锁继续使用 `GuideUnlockService`，完整阅读继续监听 `GuideCompletedEvent`。

## 验证命令

```bash
./gradlew build compileGameTestJava acceptanceTestJar
./gradlew runGameTestServer -PjeiServerAudit
./gradlew runFrameworkAcceptanceServer -PframeworkAcceptanceAudit
./gradlew runClient -PshopSearchRuntimeAudit
./gradlew runClient -PmarkerTextRuntimeAudit
./gradlew runClient -PhudStyleRuntimeAudit
```

三项客户端验收从标题界面开始，使用 `build/client-audits/` 下各自独立的实例，也不会打开已有世界。

本次在 NeoForge 21.1.251 上通过 930 项 JUnit、45 项常规 GameTest、9 项框架验收和 69 项编辑器测试。真实客户端验收通过完整及快捷商店搜索、18 个任务标记渲染场景，以及两档 GUI 缩放下的 132 张 HUD 截图。对话交付和指南生命周期的网络格式已覆盖往返测试；本次未运行附属模组的完整交付和指南生命周期场景。
