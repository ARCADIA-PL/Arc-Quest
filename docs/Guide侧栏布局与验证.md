# Guide 左侧阅读栏

## 设计约束

Guide 使用左侧局部占屏的阅读栏。右侧保留正常游戏画面，不绘制全屏遮罩、不将阅读页改成居中弹窗。独立 GuideScreen 和非强制打开的 GuidePopupOverlay 复用相同的布局与正文渲染。

- 常规宽度约为 GUI 视口的 30%，在 210–340 GUI 像素之间调整；最小视口限制为其宽度的 62%，避免侧栏超出屏幕。
- 高度在视口内保留上下边距，最大 580 GUI 像素。图片始终在正文上方，高度最多 104 GUI 像素，同时不得超过可读内容区的 40%。
- 标题最多在固定栏头显示两行；更长的标题完整进入滚动正文。摘要不再截断为三行。
- 摘要与正文按真实缩放字号换行、计算行高、裁剪和滚动范围。颜色与粗体保持原有文本样式。
- 页码、上一页、下一页和 Aa 字号设置保留独立底栏。关闭叉号采用几何绘制，避免字体缺字和居中偏差。
- 滚轮滚动正文，左右方向键 / A、D 翻页，Home / End 到达首尾，Page Up / Down 滚动一屏。
- 调整窗口和字号保留阅读比例及当前页；不重新播放场景、不重新发送 OPENED。字号设置临时进入 SUSPENDED，返回时 RESUMED；真实关闭才发送 CLOSED。
- 同一指南正在阅读时不再重复显示解锁提示图标；其它指南的解锁提示延后。原生 Keybind 组件改变真实绑定后也会刷新缓存。

## 代码位置

- `GuideReaderLayout`：布局几何、缩放行高和滚动条滑块尺寸。
- `GuideReaderPanel`：共用正文缓存、渲染、裁剪及输入命中。
- `GuideScreen`：独立屏幕、分页和服务端关联的阅读生命周期。
- `GuidePopupOverlay`：叠加式打开、原对话恢复和分页。
- `GuideSplashRenderer`：防止解锁提示覆盖已打开指南。

## 验证方式

`gradlew.bat build acceptanceTestJar --offline --console=plain` 完成 ArcQ 编译、打包与 JUnit。布局测试覆盖 320×240 至 2560×720 的 GUI 视口、50%–200% 字号、长标题、图片 / 无图片页面、正文与底栏不重叠、滑块不超出轨道。

实际客户端验证由 DuelQuest 的 QA 源集 `GuideReaderClientSmoke` 驱动：静音、5G、单客户端，测试真实 GLFW 窗口、GUI 缩放、中英文全页文字、滚轮 / 拖拽 / 翻页点击、窗口变化后阅读位置、字号面板返回及真实按键重绑定。该测试类不进入发行 JAR。

招架教学同时回归 Guide 打开后的双方减速、字号面板暂挂 / 恢复、ESC 真实关闭后恢复动画以及三次真实反斩。
