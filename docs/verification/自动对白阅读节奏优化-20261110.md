# 自动对白阅读节奏优化

日期：2026-11-10。自动节点采用中等节奏，总阅读预算包括打字时间。

## 行为

- 非空正文预算：`max(注册delay, clamp(1200 + 有效字数 × 120, 3000, 24000))` 毫秒；注册停顿沿用原先30秒上限。格式码和空白不计字数，标点及Unicode字符计数。
- 10字约3秒，50字约7.2秒，100字约13.2秒，200字约24秒。时间从文字开始显示累计，打字动画包含在内。
- 必须打完全文，并额外保留至少600毫秒，才允许自动跳页。空白兼容页预算600毫秒，同时遵守注册delay。
- 计时与打字使用相同的单帧100毫秒上限；打开历史、任务大标题或交互指南时暂停，不因卡顿突然连跳。节点更新及界面初始化重置计时。
- 空格/回车/点击的原手动显字、推进，以及ESC关闭处理保持原样；原服务端会话与奖励事务未改动。
